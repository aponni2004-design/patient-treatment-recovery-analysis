Patient Treatment & Recovery Analysis Dashboard

An interactive Excel dashboard developed to analyze patient treatment, recovery, cost, demographic, and departmental data. The project demonstrates practical skills in **Excel-based data analysis, KPI reporting, data visualization, and dashboard development**.

 📊 Project Overview

The dashboard analyzes **200 patient records** and provides an interactive view of treatment and recovery-related metrics.

The objective is to transform structured patient data into meaningful KPIs and visual reports that can help users compare treatment outcomes, departments, doctors, patient demographics, and cost categories.

 🎯 Objectives

* Analyze patient treatment and recovery patterns
* Track important healthcare KPIs
* Compare recovery performance across departments and doctors
* Analyze treatment types and patient demographics
* Examine treatment cost categories
* Present findings through an interactive Excel dashboard

🛠️ Tools & Technologies

* Microsoft Excel
* PivotTables
* Pivot Charts
* Excel Filters / Slicers
* KPI Cards
* Data Cleaning & Organization
* Data Validation
* Data Visualization

📈 Key KPIs

The dashboard provides the following key metrics:

| KPI                    | Description                            |
| ---------------------- | -------------------------------------- |
| Patients Count         | Total number of patient records        |
| Average Treatment Cost | Average cost associated with treatment |
| Average Patient Age    | Average age of patients                |
| Average Stay           | Average length of stay                 |
| Average Recovery Score | Overall recovery performance           |

 🔍 Analysis Performed

Treatment Analysis

Compared average recovery scores across different treatment types, including:

* Medication
* Observation
* Surgery
* Therapy

Department Analysis

Analyzed recovery performance across departments such as:

* Cardiology
* Gastroenterology
* Neurology
* Oncology
* Orthopedics
* Pediatrics

 Doctor Performance

Compared average recovery scores across individual doctors to identify differences in treatment outcomes.

 Demographic Analysis

Analyzed patient recovery and distribution across:

* Gender
* Age groups
* Patient categories

 Cost Analysis

Categorized treatment costs and compared recovery performance between different cost groups.
